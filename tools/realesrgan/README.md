# Standalone AI Lite (optional)

Place the NCNN Vulkan runner under `win-x64/` or `linux-x64/` and model files under `models/`. See `THIRD_PARTY_NOTICES.md` and `MANIFEST.json`.

From the repo root:

```bash
npm run setup:ai-lite
```

This downloads official artifacts (see manifest) into ignored folders. You can also copy files manually.

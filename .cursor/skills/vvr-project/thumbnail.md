# Thumbnail Studio (deep)

Own Pinia store `useThumbnailStore` (`client/src/apps/thumbnail-studio/stores/thumbnail.ts`) with IndexedDB library helpers in `thumbnailProjectLibrary.ts`. Ranking and screensaver stores stay independent. Multi-project layout matches Screensaver: sticky **Image** drop (multi-file, each extra file becomes its own project), scrollable **Projects** list (`ThumbnailMediaPanel.vue`, `ThumbnailProjectList.vue`), card click to open, rename/duplicate/delete, **Delete all**, upload details on an info icon (no status box under the drop zone), and cards dim at 50% opacity when the downloaded file still matches the saved export fingerprint. Header **New project** saves the current work and opens a blank draft (not listed until an image is added). The document is version 2 in `shared/thumbnailProject.ts`: project name (`Untitled thumbnail` default), one image, a resolution badge, a duration badge, and export settings. There is no layer list. Preview and export both call `renderThumbnail` in `client/src/apps/thumbnail-studio/lib/renderThumbnail.ts`. Framed screensaver artwork is drawn with `bakePlacement` / `paintComposition`. The preview long edge is 960px. A full-size canvas is created only when downloading.

The screen is a 16:9 preview plus Image, Resolution Badge, Duration Badge, and one Badge style section, and **Download Thumbnail**. Both badges default off (Show badge toggles resolution/duration/position controls and the shared Badge style section). Default look when enabled is gold plate: resolution `4K UHD` at the top left, duration `2 HOURS` at the bottom left. Badge styles are baked SVG artwork (gold plate, silver plate, gold stack, silver stack, gold, silver, outline, invert) under `client/src/assets/thumbnail-badges/`. `shared/thumbnailBadges.ts` maps badge text + style to a slug; preview uses `<img>` (`ThumbnailBadge.vue`) and download rasterizes the same SVG (`rasterizeBadge.ts`). One style choice updates both badges. Badge size is a shared slider from 40% to 200%. Resolution and duration come from dropdowns in `RESOLUTION_BADGE_OPTIONS` / `DURATION_BADGE_OPTIONS` (`shared/thumbnailBadges.ts`); each label maps to one SVG slug per style (chips use compact slugs such as `4k` / `30m`). Style previews always show the 4K artwork (`4k` or `4k-uhd`). Text and position stay separate. The preview paints the image on canvas and overlays badge images aligned to the same anchor box as export.

Positions are nine presets, edge distance in export pixels, and X/Y offsets; anchor math converts to normalized coordinates so export matches the preview. Dragging a badge sets a free position and leaves it there. Choosing the same preset corner for both badges nudges the one just changed, unless the other badge was dragged there on purpose.

Uploads are PNG, JPEG, or WebP (default cover crop in the document; no image fit/pan controls in the panel). **Create Thumbnail** on Screensaver stages the transfer in IndexedDB and applies it in the background: a new thumbnail project is created per screensaver project id, and a later click on the same screensaver project replaces that linked thumbnail only. The app stays on Screensaver (no route change). Opening Thumbnails still consumes `pending-transfer` when navigation is used (e.g. **Update from Screensaver**). A transfer copies the current image (or the existing still for a video), composition, frame PNG, output size, and duration, and fills badges from output size and duration. Shorts no longer sends thumbnails. If a picture is already open on the Thumbnails route without a background apply, the transfer asks Keep or Replace.

Export is 16:9 PNG or JPEG at 1280×720 (default), 1920×1080, or 3840×2160. JPEG has a quality slider. Download uses the project name in the filename when it is not the default (`thumbnailDownloadFilename`). Download does not use FFmpeg.

`npm run test:thumbnail` runs the shared contract tests.
Badge SVGs are committed under `client/src/assets/thumbnail-badges/` (catalog slugs in `shared/thumbnailBadges.ts`).

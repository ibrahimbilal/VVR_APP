# Image Upscaler (deep)

Editor state is `useImageUpscalerStore` (`client/src/apps/image-upscaler/stores/imageUpscaler.ts`). It is not written to IndexedDB. The left column matches the other editors: the project name and image drop stay fixed under a bottom border, and the image list scrolls. Cards use the light selection border, a status pill beside the file name, and icon actions. A downloaded card stays at 50% opacity until that image is upscaled again. **Delete all** sits above the list and **Download all** is pinned under it. Narrow screens use Source, Preview, and Settings tabs. Jobs run **upscale** then **export** in `server/src/imageUpscalerJobs.ts` (`runUpscaleStage` on the engine, `runExportStage` in `imageUpscaler.ts`). Intermediates live in `upscaler/<jobId>/mid/` keyed by content SHA-256 + upscale params; inputs are kept until purge. Default engine is Lanczos3; optional `realesrgan-lite` runs NCNN at 4× then fits the intermediate to the effective scale (see `realesrganEngine.ts`). Settings add `scaleFactor` (`auto`|1–4). Export resolution presets include **original** and **upscaled** alongside FHD–8K and custom. `POST /api/image-upscaler/jobs/:id/re-export` re-runs export only. AI setup unchanged (`RIBO_AI_UPSCALER_ENABLED`, `tools/realesrgan/`). Capabilities gate AI in the UI. Failed AI jobs are not replaced with Standard.

The app always exports the **upscaled** pixel size in the **same format as the first uploaded image**. JPEG is written at quality 100. Engine is **lanczos3** by default, scale **auto**. The export settings panel and the comparison “inspect full resolution” view are not in the UI. Sharpen stays off. Concurrency and FFmpeg yield rules unchanged. **Skip Lanczos resampling** still applies on export when pixels already match and the server options allow it. Limits: 40 MB, 8 files, 7680×4320 output, `RIBO_REALESRGAN_MAX_INTERMEDIATE_EDGE` for AI/ intermediate caps (`docs/image-upscaler.md`).

**Send to Screensaver** fetches the full output file. If Screensaver already has a source, the user must confirm. Replace calls `acceptExternalImage`, which uses the same image-drop path as `pickSource` (static mode, reframe, keep frame id). Duration, output resolution, audio, and encoder are not reset. Cancel leaves Screensaver unchanged.

Comparison previews are WebP with a 1440px long edge. Downloads are the verified full-size files. Preview and download URLs use `outputRevision` (and file size as a fallback) so re-export after a crop change always reloads. `npm run test:upscaler` covers dimensions, resize modes, alpha, JPEG flatten, rejection, batch, ZIP names, cleanup, cancel, re-export crop, and preview versus download.
